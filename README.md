# 🍎 Apple Knight Adventure (苹果勇者大冒险)

🔗 **[点击这里直接游玩在线 Demo！https://appleknight.vercel.app/]**

这是一款基于 `Phaser 3` + `TypeScript` 开发的 2.5D 动作角色扮演游戏 (A-RPG) 垂直切片 Demo。

## 🎮 核心机制与玩法 (Features)

* **纯正的 2.5D 空间遮挡**：利用动态 Depth 排序与多层 Tiled 地图，实现了天桥/树冠的真实物理遮挡与边缘保护。
* **硬核 ACT 战斗系统**：
  * **翻滚与无敌帧**：带有独立状态锁死的无敌闪避系统。
  * **多段连击与招式派生**：支持输入缓冲 (Input Buffering)，获取特定道具后解锁具有独立判定和动作的第三段重击。
  * **动态伤害与 DOT 机制**：包含击退反馈、受击硬直，以及宠物附带的叠加流血与吸血系统。
* **高阶 Boss 状态机**：拥有独立的霸体/削韧系统，双技能随机释放，并在破防后支持玩家进行 QTE 处决。
* **魂系箱庭解谜**：支持带有方向判定的单向门捷径解锁、UI 对话框事件阻断、宝箱动态掉落与外观热重载。

## 🕹️ 操作说明 (Controls)

* **移动**：`W` `A` `S` `D` 或 `↑` `↓` `←` `→`
* **翻滚 (带无敌帧)**：`Space (空格键)`
* **攻击 / 连击**：`鼠标左键` 或 `J`
* **互动 (开门/开宝箱)**：靠近目标按 `F`
* **处决 Boss**：Boss 陷入蓝色虚弱状态时，贴身按 `鼠标右键`  或 `K`

## 🛠️ 技术栈 (Tech Stack)

* **引擎**：Phaser 3 (开启 WebGL `pixelArt` 模式完美还原像素质感)
* **语言**：TypeScript (严格的面向对象与状态机架构)
* **构建工具**：Vite
* **地图编辑器**：Tiled Map Editor (JSON 导出与多图层解析)
